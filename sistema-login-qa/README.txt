# Sistema de Login - Atividade de Teste de Software

Esse é um sistema front-end simples para utilização em aula para os alunos da universidade Uniandrade de Curitiba/PR

## Como executar
Abra o arquivo `index.html` em um navegador.

## Conta de demonstração
E-mail: aluno@qa.com

## Objetivo da atividade
Os alunos devem testar o sistema utilizando:
- Caixa-preta
- Caixa-branca (apenas análise conceitual da lógica)
- Teste exploratório

Observação: o sistema é apenas didático e não possui backend ou banco de dados.
